# Локальный звук V8

Файлы чужих записей не используются. Звук генерирует `js/audio.js` через Web Audio API: V8-гармоники, фильтрованный шум, старт, холостой ход, rev и burble. Поэтому аудио работает офлайн, не требует декодирования или лицензий YouTube/Freesound.

Это авторская художественная синтезация, не запись конкретного двигателя Cadillac 6.2L. Код MIT. Начальная громкость 25%; звук запускается только после клика и выключается при скрытии вкладки. Возможность проигрывания зависит от браузера и системной громкости.
