# Escalade V Studio · V2

[Открыть сайт](https://karimov0913.github.io/Cadillac-project/)

Независимая фотографическая студия Cadillac Escalade-V ESV: настоящие заводские изображения вместо процедурного макета, кинематографические характеристики, отдельный 2D-конфигуратор и записанный стереозвук V8.

## Что изменилось

- Главный экран: точное заводское изображение длиннобазной **ESV**.
- V / 360°: 16 заводских кадров **стандартного Escalade-V**, вращение перетаскиванием/стрелками, автовращение после 5 секунд бездействия. Это photo turntable, не свободная 3D CAD-модель. Приближение: +/− или Ctrl + колесо.
- Салон 360°: фотографическая панорама V-Series, Three.js + OrbitControls, динамическая загрузка; 2D-резерв при отсутствии WebGL 2.
- Пять полноэкранных сцен: двигатель / 682 hp, 4,4 с, Brembo, 55″ дисплей, 38 динамиков AKG. GSAP закрепляет экран, текст входит снизу, планы плавно меняются с масштабом, сдвигом и расфокусом; затем обычная прокрутка. Reduced motion показывает сцены без закрепления/анимации.
- Цвета кузова и интерьера меняют **только соседнее 2D-превью**. Главный автомобиль не меняется. Превью закреплено рядом с панелями, на телефоне — над ними.
- Пять официальных оттенков + синий кастомный эскиз (не заводская опция). Два официальных салона V-Series + два справочных салона Luxury с явными подписями.
- Настоящая бинауральная запись V8, не синтез: холостой ход, газ и сброс, сохранённое стерео. Конкретная машина неизвестна; не выдаётся за подтверждённый звук Escalade.
- Сравнение с источниками/оговорками, галерея, калькулятор топлива, тема и настройки в localStorage, ссылка конфигурации, офлайн-кэш.

## Запуск

Требуется Node.js 22+ и npm. Команды выполняются **в терминале**, не в YAML и не в редакторе GitHub:

```bash
git clone https://github.com/Karimov0913/Cadillac-project.git
cd Cadillac-project
npm ci
npm start
```

Локально: http://localhost:4173/. `npm run build` создаёт `dist/`; `npm run preview` запускает готовую сборку. `file://` не поддерживает модули и Service Worker.

## Публикация

GitHub Pages использует **GitHub Actions**. Существующий `.github/workflows/pages.yml` выполняет npm ci → npm test → npm run build → Pages. Обновление `main` автоматически публикуется.

При локально настроенном Git с правом записи:

```bash
npm run deploy
```

Команда тестирует, собирает, коммитит изменения при необходимости и делает push в main. GitHub может попросить авторизацию. Не вставляйте эти команды в workflow-файл. Для следующего просмотра старой вкладки после обновления используйте Ctrl+Shift+R.

## Структура

```text
index.html
css/style.css
js/app.js                 # скролл, независимое превью, UI
js/configurator.js        # ESV / photo turntable
js/panorama.js             # фотографическая кубическая панорама
js/audio.js                # запись V8 / Web Audio
js/data.js                 # характеристики, источники, расчёты
asset-packs/*.json.gz.b64  # переносимые пакеты изображений/аудио
scripts/build.mjs          # распаковка, bundle, offline SW
scripts/serve.mjs
scripts/deploy.mjs
deployment/pages.yml       # шаблон рабочего Actions workflow
tests/data.test.mjs
tests/browser-qa.mjs
tests/qa-results.json
SOURCES.md
README.md
```

Сборка распаковывает медиа из `asset-packs/` в `dist/assets/v2/`. Это реальные файлы WebP/MP3, не сетевые запросы к Cadillac на каждом просмотре. Исходные бинарные копии `assets/v2/` опциональны и игнорируются Git; чистый клон собирается только из пакетов. Three.js панорамы загружается отдельным JS-чанком. Все рабочие пути относительные и поддерживают `/Cadillac-project/`.

## Проверки

`npm test` — данные, математические крайние случаи и структура сцен. `tests/browser-qa.mjs` — дополнительная проверка через Playwright, с отдельно установленным Playwright и Chromium; запустить preview, затем `node tests/browser-qa.mjs`. Переменные `QA_URL` и `CHROMIUM` позволяют указать адрес/браузер. Результаты записываются в `tests/qa-results.json`.

Проверяются ширины 375/1920, независимость превью, pinned-сцены, вращение, панорама, загрузка стереозаписи, кнопки звука, калькулятор, тема, отсутствие ошибок, офлайн и reduced motion. Автоматические проверки аудио подтверждают декодирование/стереоканалы, но не заменяют субъективное прослушивание.
